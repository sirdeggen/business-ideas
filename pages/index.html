Receivable desk

Who do we chase today? A collections list on this desk’s registry — on time / a bit late / call them / board should know. Not a bank. Overlay and settle are local Docker, not live from Pages: cd receivable-desk && docker compose up --build (overlay :8082, UI :5175).

Event tickets

Tickets you can send, show on a phone, and spend at the door so they can’t be used twice. Overlay is local Docker, not GitHub Pages: cd event-tickets && docker compose up --build (overlay :8080, UI :5173).

Pages UI (no public overlay): /tickets/
