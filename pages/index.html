BSV business ideas

First versions, shipped fast. Tickets and the receivable desk are static demos here; invoices, treasury, and the HTTP 402 servers run from their repo folders (local Docker, later on a cluster). The receivable overlay is localhost — settle does not work from GitHub Pages.

Event tickets

Mint a tranche, hold a QR, transfer by spend, redeem at the door. Tickets are BSV UTXOs in a BRC-100 basket.

Receivable desk

Public invoice registry (who is owed, by whom, amount, due, status). Advance 70% is a stub. BSV only. Not a bank. Overlay is localhost — settle does not work from GitHub Pages until you run cd receivable-desk && docker compose up --build (overlay :8082, UI :5175).

Pages path: /receivables/

Invoices

Payable invoices on BSV. Payee creates a PushDrop UTXO; payer settles with BRC-29. Overlay is the audit trail. Local Docker, not a Pages demo.

Live cluster path will be /invoices

Treasury

Grassroots BSV treasury, 2-of-3 (BRC-47 P2MS). Create, invite signers, fund, propose, approve, export CSV. Not an EVM Safe, not a custodian.
