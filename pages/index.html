Business ideas

Invoices first: send a payable, get a receipt. The receivable desk is a collections list (this desk’s own registry), not a second product. Tickets sit after invoices. Tickets and the desk persist on the public overlay (overlay-us-1.bsvb.tech / tm_anytx). Local Docker custom topics remain an optional override. Chrome hides BSV Desktop until you Allow “sirdeggen.github.io wants to Access other apps and services on this device,” then Retry with Desktop unlocked.

Receivable desk

Who do we chase today? A collections list on this desk’s registry — on time / a bit late / call them / board should know. Not a bank. Register, list, and mark paid persist on the public overlay (overlay-us-1 / tm_anytx / ls_anytx, filtered to receivable fields). Local Docker tm_receivables is optional: cd receivable-desk && docker compose up --build (overlay :8082, UI :5175).

Event tickets

Tickets you can send, show on a phone, and spend at the door so they can’t be used twice. Mint, transfer, redeem, and door lookup persist on the public overlay (overlay-us-1 / tm_anytx / ls_anytx, filtered to Demo Night tickets). Local Docker tm_tickets is optional: cd event-tickets && docker compose up --build (overlay :8080, UI :5173).
