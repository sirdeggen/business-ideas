# business-ideas

First versions of BSV product ideas, shipped fast.

## event-tickets

Tickets as BSV UTXOs: mint into a BRC-100 basket, hold/show a QR, transfer by spend, redeem at the door.

See [event-tickets/README.md](./event-tickets/README.md) for mint, transfer, redeem, and how to run the overlay locally.

Try the static demo on GitHub Pages: https://sirdeggen.github.io/business-ideas/
