# business-ideas

First versions of BSV product ideas, shipped fast.

## event-tickets

Tickets as UTXOs: mint into a BRC-100 basket, hold/show a QR, transfer by spend, redeem at the door.

## 402-publisher

A Ghost-class page that charges readers and crawlers per fetch. HTTP 402 on BSV (BRC-121), sats, two prices. No accounts.
